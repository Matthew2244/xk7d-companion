# Parameter table review

The table in `Sources/XK7DCore/Resources/parameters.json` is generated by
`tools/generate_parameters.py` from rows transcribed by hand from the Owner's
Manual V1.10, pages 176 to 185. This file records how it was checked and every
place where the manual is unclear or contradicts itself.

## How it was checked

1. **Automatic cross-check against the text export** (`tools/verify_against_manual.py`,
   given `pdftotext -layout` of the manual). For every transcribed row it looks for one line
   holding the manual's parameter name, the NRPN bytes, the five address bytes
   and the length, in that order. Result: **318 of 320 rows match name and
   bytes; 2 match bytes only** (the two "Cust. TW Total Level" rows, whose name
   wraps onto a second line), **0 not found**. Those two were checked on the
   page image of p. 182.
2. **Range cross-check.** The same script reads the Data column and compares
   its first and last raw value with the table. This found three real errors
   in the first transcription, all fixed: Leslie fast speed (`02 2D` is
   2×128+45 = 301, not 0x22D), mic distance (`01 48` = 200), and Master Tune
   (`03 2E`..`03 42` are two 7-bit bytes, so the raw value is the pitch in Hz,
   430 to 450). A fourth error, in the generator itself, was caught by the
   Swift unit test of the Favourites example: the placeholder `ff` in
   `50 ff` had been read as the byte FF. Placeholders are now matched by name
   before hex, and the generator and the tests both refuse any address byte
   above 7F. The remaining differences it prints are its own parsing limits
   on two-column lines, or the deliberate choices listed below.
3. **Row-by-row comparison with the page images.** `tools/print_table.py N`
   prints the generated table for page N in the manual's own terms (manual
   category and name, NRPN, address, length, raw range in the manual's byte
   notation, labels). Every page from 176 to 185 was opened as an image and
   compared line by line with that listing: every row, every address byte,
   every length, every range and every choice list, including the zone and bank
   expansions (6 external zones × 17, 10 Patch Load banks × 11) and the index
   ranges of the custom tables (108-wheel and 96-wheel numbering, footage codes,
   61-key numbering, formants, favourites). Page 157 (Device ID) and 100
   (tone wheel brake) were also checked. No differences were found beyond the
   items below.
4. **Menu pages.** A second pass read the menu pages that describe the same
   settings (the display's own ranges and names) to settle what the MIDI
   tables leave unclear. Those are marked "Settled" below.
5. **Worked examples.** Every example printed in the manual is a unit test in
   `Tests/XK7DCoreTests/ManualExampleTests.swift`, encoded through the
   generated table, not through hand-written bytes.

The text export silently drops the sharp sign (♯). Places that read "Bank[C]",
"E-C", "Adjust [A]" or "A/B" in the text read "C♯", "E-C♯", "A♯" and "A♯/B" on
the page. The table follows the page.

## What is in the table

All rows of all tables: Patch (pp. 178-181), Custom Tone Wheel, Custom
Contact, Custom Pedal Registration (p. 182), Custom Pipe and Custom Leslie
(p. 183), System (pp. 184-185) and Favorites (p. 185). 537 entries in all, 58
of which carry index pickers (tone wheel, key, footage, formant, favourite key).

Left out, because the manual gives them no MIDI address: Auto Power Off,
Device ID and Rx Dump (p. 184). Drawbar control changes, program changes and
the other controllers (pp. 176-177) are handled in code, not in the table.

## Where the manual is unclear, and what the app does

| Parameter | What the manual says | What the app does | Confidence |
|---|---|---|---|
| Tone wheel brake range (18 00) | Data `34 – 64 – 4C (-24 – 0 – +12)`. 34h is -12, not -24, from a centre of 40h. The menu page (p. 100) says -24 to +12. | Raw 28h to 4Ch, centre 40h (-24 to +12). | Inferred. The top and centre agree with both readings; only the bottom differs. |
| Vibrato mode (12 01) | `00 – 05 (V1 – C3)`; no order given. | V-1, C-1, V-2, C-2, V-3, C-3: the order the positions are printed around the knob on p. 58, clockwise from V-1, and the B-3's. (1.0 used V-1, V-2, V-3, C-1, C-2, C-3.) | **Inferred** from the drawing. Needs the organ. |
| Custom cabinet (12 0E), custom TW / pipe / sub drawbars (10 07, 10 09, 1F 04), custom contact (10 08) | MIDI tables: `U1 – F10`, `U1 – F4`, `U1 – F3`. Menu pages: "U1 – U10, F1 – F10" for the Leslie cabinet (p. 119), "F1 – F4, U1 – U4" for others, and "U1 – U4, F1 – F4" for the custom contact set (p. 84), which also disagrees with the MIDI table's six values. | User sets first, then Factory. | Unresolved; follows the MIDI tables. |
| Fold-back keys (10 00 00 00 03 / 04) | MIDI table: `00 – 0C (TW#01 – #12)`, 13 values for 12 names, and `00 – 05 (TW#91 – #96)`. | Keys 1C to 2C and 4G to 5C. | **Settled** by the menu (p. 109), which shows these keys; the counts match. |
| Percussion decay (11 06, 11 07) | `00 – 18 (0 – 24)`. | 1 to 24, then Cont. | **Settled** by the menu (p. 85): "1 – 24, Cont" is exactly 25 values. |
| External zone program change (3x 04) | `00 – 7F (0 – 127)`. | Shown 1 to 128. | **Settled** by the menu (p. 103). |
| Preset key hold time (09 02) | `00 – 0A (0.0 – 1.0 sec)`. | 0 to 100 ms in 10 ms steps, as the menu (p. 137) says. | Units conflict; the display will tell. |
| Expression polarity and curve, damper modes, vibrato type, pipe chiff | MIDI table names differ from the menu's. | Both names where they differ, for example "Norm (H or R)", "1 (B-3)", "Big Box ('57-59)"; chiff "Mid" as on the menu. | Order from the MIDI table; names from both. |
| Organ type (10 04) | Range `00 – 04` but lists `05: Pipe`. | 00 to 05 including Pipe. | Confident (the organ has six types). |
| Assign knob functions (19 00-02, 19 06-08) | Range `00 – 17` but the list runs to 1D (EXZ CC). | All 30 listed choices. | The six EXZ CC choices may not exist. |
| Assign knob CC (19 09-0B) | List skips 1C to 1F; "2E-34: Undefined 85-90" overlaps 2E. | 1C-1F labelled "not listed in the manual"; 2F-34 = CC 85-90. | 1C-1F are probably CC 66-69 but the manual does not say. |
| Assign buttons (19 03-05) | Table heading says XK-7; the specification says the buttons are XK-7D only. | Included, with a note. | Address confident; which model uses it unclear. |
| Foot switch modes (03 00-04) | Range `00 – 28` but lists 29 and 2A (To Adjust A♯/B). | 00 to 2A. | Confident. |
| Organ sounding point (09 01) | `00 – 07 (Patch, 1 – 7, Velocity)`: nine names for eight values. | Patch, 1-6, Velocity. | **Settled** by the menu (p. 137). |
| Pedal sub drawbar level (31 00 00 0g 0k) | `00 – 08 (0 – 9)`. | Shows the raw 0 to 8. | The display may read 1-9 or 0-9. |
| Custom pipe stop assign (51 00 0p 0x 00) | Range `00 00 – 00 2D (C-Open Diapason – P-Cornopean)`, but 2D is the 46th stop, and the stop list on p. 174 has P-Cornopean at 44, then Reserved 1 and 2. | 46 stops, S01 to S46, ending with the two Reserved entries. | Confident. The manual's label for the end of the range is off by two; its example (S04 = `00 03`) matches. |
| Custom pipe, Pedal part (51 00 0p 0x ..) | Part list says 3 = Pedal; footage note says "(p=2) 0, 1 = 16´, 8´". | Part 3 for Pedal, drawbars 16´ and 8´. | **Guess.** Could be part 2. Needs the organ. |
| Impedance (14 00 00 nn 0g) | Does not say which footages g covers. | The nine manual footages. | Guess. |
| Leslie horn/drum level (43 00 00 0r 00) | Length 02, but the data is written as single bytes `00, 01 – 4D`. | Two bytes, `00 00` to `00 4D`. | Follows the length column. |
| Leslie mic distance (43 .. 04) | Horn `00 1E – 01 48 (0 – 170 cm)`, drum the same raw range `(30 – 200 cm)`. | Raw 30-200 shown as 0 to 170 cm for both. | **Settled** by the menu (p. 121): 0 to 170 cm for both. |
| Leslie mic width (43 .. 02) | MIDI table `00 – 64 (0 – 100 cm)`; menu 0 to 40 cm or Side (p. 121). | The raw number, 0 to 100, with no unit. | Unresolved. |
| Preamp expression order (14 05), preamp type (14 03), vibrato type (12 02) | Menu names differ from the MIDI table (four choices vs two for 14 05). | MIDI table names and ranges. | Confident for the address; names may not match the display. |
| Patch Load banks (4b 00-0A) | Only "b = Bank". | b = 0 to 9 for banks C to A. | Inferred. |
| Favourite keys (50 ff / 51 ff) | `ff: 00 – 63 (C-C – A-A)`; example E-C♯ = 29h. | ff = bank × 10 + key, keys C, C♯, D ... A. | Confirmed by the manual's example. |
| Values given only by end points | Vibrato rate (5.78-7.90 Hz), emphasis frequency, EQ frequencies, Leslie rise/fall/brake times, contact delay. | Shows the end points and "step N of M" in between. | Deliberate: the curves are not published, and a guessed number spoken aloud would mislead. |
| Expression Source example (p. 185) | SysEx example `... 04 00 01` and the table (Source = NRPN 04 00) agree, but the printed NRPN example reads `Bx 63 04 Bx 62 01 Bx 06 01`, which is the Device parameter. | Follows the table: 63 04 62 00. A unit test records the misprint. | Confident; misprint in the example. |
| Device ID | Range 0-127, no stated default. | Default 0, and the app adopts whatever ID the organ answers with. | The p. 157 screenshot shows 0. |
| Dump check digit | "Lower 7 bits of XOR [DATA]". | XOR of the 128 nibblized bytes; incoming packets are accepted if either the nibblized or decoded reading matches, and the app records which. | Ambiguous until a real dump is captured. |

## Second check (1.0.1)

An independent reviewer compared a fresh sample of about 48 rows, spread over
every page from 176 to 185 and avoiding the rows above, with the page images:
address bytes, NRPN, length, raw range, display scaling at both ends and the
centre, and every choice label and its order. No errors were found. The only
new note is the stop assign label above. Pages 176 and 177 (drawbar
controllers and levels, program change banks, other controllers, NRPN and
identity) also matched the code.
